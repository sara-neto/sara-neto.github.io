// About me

Where data meets
clinical precision.

I spent five years as a Cardiac Physiologist, interpreting ECGs, Holter monitors, and stress tests — work that demands meticulous attention to signals in noisy data. That precision and discipline now drive how I approach data challenges.

I'm completing a Master's in Information Management (Business Intelligence) at NOVA IMS to formalize this career shift, building hands-on expertise in SQL-based ETL pipelines, Power BI/DAX dashboards, and the Microsoft Fabric ecosystem, alongside growing Python skills for data science and machine learning.

My thesis evaluated the Samsung Galaxy Watch 4 as a clinical-grade ECG device — combining clinical expertise with signal processing, data collection, and statistical validation. A rare blend of domain knowledge and technical skill, and the foundation for a long-term path in data-driven decision making.

BI Project · NOVA IMS · Sep–Dec 2025

UFO Sightings — Enterprise Data Warehouse

Built a full enterprise BI architecture using UFO sightings data as a case study. Designed a layered Lakehouse → Staging → Data Warehouse stack using Kimball dimensional modelling principles. Defined fact table grain, created surrogate keys and dimension tables, performed data cleaning and standardisation, and automated the ETL workflow through Microsoft Fabric Pipelines and Dataflows.

Microsoft Fabric SQL Kimball Modelling ETL Pipelines Data Warehouse
